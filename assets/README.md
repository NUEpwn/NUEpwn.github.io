# NUEpwn Logo

| Datei | Verwendung |
|---|---|
| `nuepwn-logo.svg` / `.png` | Hauptlogo (600×360, PNG in 1200×720) |
| `nuepwn-icon.svg` / `nuepwn-icon-512.png` | Quadratisches Icon, z. B. Avatar für Discord, CTFtime, GitHub |

Der Schriftzug ist in Pfade umgewandelt (JetBrains Mono Bold), das SVG braucht also keine installierte Schrift.

## Farben

| Name | Hex |
|---|---|
| Hintergrund | `#0d1117` |
| Linie / Schrift | `#e6edf3` |
| Akzent (Prompt, Flagge, Cursor) | `#3ddc84` |
